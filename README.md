# متابعة TRONIX
أداة متابعة نواقص وتاسكات الماكينات (بالعربي).

- `index.html` = الهيكل بس (HTML)، بيتفتح من GitHub Pages.
- `css/style.css` = كل التصميم.
- `js/` = الكود، مقسّم حسب الوظيفة (الترتيب في index.html مهم، متغيّرهوش).
- `supabase/` = ملفات قاعدة البيانات (بتتشغّل مرة واحدة في Supabase ← SQL Editor).

## خريطة ملفات js/ (بالترتيب)

| الملف | فيه إيه | يتعدّل لما تطلب |
|---|---|---|
| `core.js` | الحالة العامة، الصلاحيات، الدوال المساعدة، حسابات التاسكات والتقدم والمراحل | منطق الحسابات / الصلاحيات |
| `ui-common.js` | الملفات المرفوعة، النوافذ (modal)، الطباعة وPDF | شكل الطباعة / النوافذ |
| `views-main.js` | render + النظرة العامة، الماكينات، ماكينة واحدة، مشاريع المصنع، لوحة المراحل | شاشات الماكينات واللوحة |
| `views-tasks.js` | تفاصيل التاسك، الأقسام والتاسكات، المتابعة، مهامي، الإعدادات | شاشات التاسكات والإعدادات |
| `forms.js` | نماذج الإضافة والتعديل وحفظ التاسك | حقول الفورم |
| `actions.js` | كل الأزرار والإجراءات (الكائن A) + التاسكات الفرعية | سلوك الأزرار |
| `supabase.js` | الاتصال بقاعدة البيانات وشاشة الدخول | الاتصال / الداتا |
| `boot.js` | تشغيل التطبيق وتسجيل الدخول | بداية التشغيل |

## نصيحة لتوفير الليميت
ارفع في الشات الملف المعني بس (مثلاً `views-tasks.js`) وقول "عدّل كذا في الملف ده فقط"، بدل رفع المشروع كله.
بعد أي تعديل غيّر الرقم في `?v=1` في index.html (مثلاً `?v=2`) عشان المتصفح يحمّل النسخة الجديدة.
